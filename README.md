# צעד עשר

אפליקציה פשוטה לחשבון נפש יומי (צעד 10), בעברית, לטלפון.

- חינמית לגמרי: אין שרת, אין חשבון, אין מפתחות API ואין מעקב.
- כל מה שנכתב נשמר רק במכשיר (localStorage). שום דבר לא נשלח לשום מקום.
- עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה, ואפשר להוסיף אותה למסך הבית.

## מה יש באפליקציה

- פתיחה ראשונה: שם, לשון זכר או נקבה, ותאריך ניקיון. אפשר לשנות הכול אחר כך בהגדרות.
- פנייה בשם ובלשון הנכונה לאורך כל האפליקציה: בשאלות, בכפתורים, ברמזים ובהודעות.
- זמן נקי במסך הבית: בשנה הראשונה מוצג בגדול מספר הימים (ומתחתיו חודשים וימים). משנה ומעלה מוצגות בגדול השנים, מתחתיהן החודשים והימים שנוספו, ובקטן סך הימים.
- כפתור הבית בתחתית המסך הוא ציור של בית.
- מחשבות ותפילות: יומן אישי לכתיבה חופשית. כתיבה חדשה בכל רגע, שמירה אוטומטית, רשימה לפי חודשים, הדפסה ומחיקה. כתיבה שנפתחה ונשארה ריקה לא נשמרת. היומן נכלל בגיבוי לקובץ.
- ברכה חגיגית ביום של אבן דרך: 30, 60 ו-90 יום, חצי שנה, 9 חודשים, שנה, שנה וחצי, כל שנה שלמה, ו-100, 500, 1000 ימים (וכל 500 אחר כך). הברכה מופיעה פעם אחת לכל אבן דרך. מי שהגדירו במכשיר "הפחתת תנועה" לא יראו אנימציה.
- 36 שאלות הדו"ח היומי, עם שמירה אוטומטית תוך כדי כתיבה.
- תצוגה של כל השאלות או של שאלה אחת בכל פעם.
- הוספה, עריכה והסתרה של שאלות: רק ליום הזה, עד תאריך, או מעכשיו והלאה. אפשר להחזיר שאלה מוסתרת.
- קישורים מהמסך הראשי ל"רק להיום" (קריאה יומית) ולוח הפגישות באתר NA ישראל.
- היסטוריה לפי חודשים ולוח שנה חודשי עם סימון של ימים שהושלמו.
- הדפסה / שמירה כ-PDF.
- תזכורת יומית ביומן של הטלפון: קובץ ‎.ics עם התראה, שנוצר בתוך הדפדפן.
- גיבוי לקובץ JSON ושחזור ממנו.
- הכתבה: אין כפתור הקלטה. משתמשים בסמל המיקרופון שבמקלדת של הטלפון.
- בתוך האפליקציה אין טקסטים של הסבר. ההסברים נמצאים בדף המדריך, ששולחים לאנשים בנפרד.

## מדריך

הדף `guide.html` הוא דף נפרד ששולחים לאנשים, ולא מקושר מתוך האפליקציה. הוא מסביר בקצרה מה יש באפליקציה, ואיך מוסיפים אותה למסך הבית באייפון ובאנדרואיד, עם תמונות. התמונות נמצאות בתיקייה `guide/`. כדי ליצור אותן מחדש אחרי שינוי בעיצוב: מריצים שרת מקומי ואז `node tools/guide-images.cjs`.

## פרסום בחינם

הקבצים כאן הם אתר סטטי רגיל. אין שלב בנייה.

### אפשרות 1: GitHub Pages (מומלץ)

1. בריפו: Settings ← Pages ← תחת Source בוחרים **GitHub Actions**.
2. הקובץ `.github/workflows/pages.yml` כבר כלול. כל דחיפה ל-`main` מפרסמת מחדש.
3. הכתובת תהיה `https://<שם-המשתמש>.github.io/step-ten-hebrew/`.

### אפשרות 2: Vercel

1. ב-vercel.com לוחצים Add New ← Project ובוחרים את הריפו.
2. Framework Preset: **Other**. בלי Build Command ובלי Install Command.
3. Root Directory: משאירים את השורש (`./`).
4. Deploy. הקובץ `vercel.json` כבר כלול. זה אתר סטטי בלבד, בלי פונקציות שרת, ולכן נשאר בתוכנית החינמית.

## עדכון גרסה

כשמשנים קבצים, מעלים את המספר ב-`CACHE` בקובץ `service-worker.js` (למשל `step-ten-v2`), כדי שהטלפונים יקבלו את הגרסה החדשה.
